# SEED

Analysis code for Stromal-Enriched Metastatic Decider (SEED) in lung
adenocarcinoma, using paired primary tumor and lymph node spatial transcriptomics.

- **[Visium](visium/README.md):** preprocessing, annotation, integration, SEED and signature analysis.
- **[Single-cell](single_cell/README.md):** CYP24A1-associated pathway and regulon analyses.
- **[Bulk RNA-seq](bulk_rnaseq/README.md):** TCGA-LUAD expression and survival analyses.

Start with the [Visium setup and example run](visium/README.md).
See the [required inputs](docs/inputs.md) for bundled metadata and input paths.
